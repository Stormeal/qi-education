# Career milestone tree design reference

Captured 2026-10-18 for the
[career milestone spec](../../docs/specs/career-paths/milestones-and-achievements.md).

- [Interactive prototype](milestone-tree-prototype.html): open in a browser;
  uses local simulated progress and the existing QI Academy visual language.
- [Desktop reference](milestone-tree-desktop.png): the initial empty Technical
  Tester route, with milestone details and the existing setup steps.

Alex approved the compact tree, milestone detail treatment, three initial job
destinations and hiding other trees until exploration. **After the prototype,
Alex clarified that learners can pursue several careers at once.** Its
single-career switch controls are superseded by separate follow/unfollow,
display-focus and preview behaviors in the feature specification. They are not
an implementation contract.

Courses and prerequisite sequences are illustrative candidates. In particular,
the technical course alternatives and the API-testing prerequisite need
curriculum review; the prototype does not establish professional eligibility.
The planned Foundation on-demand option is labelled as planned, not available.

The prototype does not persist achievements, call the application API or read a
CV. Example/reset controls are design tools and are not planned product features.
Its horizontal map scrolling on a phone does not replace the specified accessible
ordered milestone view. Prototype interaction checks do not verify a product
implementation or the later multiple-career requirement.
