`/courses/valid-course/edit` and the edited title; confirming a second Back opens
the original `/courses/valid-course` page.

DEF-010 / DL-01–04: the original direct URL failure no longer reproduces. Runtime
fix `a6767f69e5254e01a47ca33b58dabe34925ea586` (2026-10-07) already permits nested
